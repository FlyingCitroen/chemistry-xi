# 2-minute demo script (target 1:50)
Use the deployed URL. 1080p, browser zoom ~110%, no music, no third-party logos. Warm the cache by
running the whole flow once before recording.

| Time | Do | Say |
|---|---|---|
| 0:00–0:10 | Match centre, profile: Casual fan / English | "Football stories don't end at the scoreline. Chemistry XI turns synthetic match events into verified, explained moments." |
| 0:10–0:35 | Click **Next key moment** 3–4 times | "Each card is a key moment. The engine decides; AI only phrases it; a Verifier checks every number. Game state shows *why* the match feels like this — control, chaos, pressure." |
| 0:35–0:55 | Keep clicking to the Alex → Jamie goal; open **Agent trace** | "This goal came from a pair our link engine had already flagged as Super Link — with uncertainty shown in the Chemistry tab." |
| 0:55–1:10 | Scroll to **overlay card**, open JSON, click Download | "Stage four: a timed, machine-readable overlay a broadcast graphics engine can place on the live feed." |
| 1:10–1:30 | Switch **Analyst**, then **日本語** (or 中文) | "Same match, a different experience: the analyst gets xG and speeds; the viewer in Tokyo gets Japanese. Same verified facts." |
| 1:30–1:45 | Favourite club + favourite player, toggle **Player focus** | "Pick a club and a player and the whole feed follows them." |
| 1:45–2:00 | **Recap** tab → Generate | "An automated recap, built from the same verified moments. Engine decides, AI explains, verifier enforces." |

A rejected draft only appears if the LLM really invents something — don't fake it. If none occurs, show
the Verifier's PASS lines and say what it would block.
